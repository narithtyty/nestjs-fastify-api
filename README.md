# NestJS Fastify API Service

## Description
A NestJS API service using Fastify as the HTTP server

## Features
- NestJS Framework (https://nestjs.com/)
- Fastify HTTP Server (https://fastify.dev/)
- TypeORM for database operations (https://typeorm.io/)
